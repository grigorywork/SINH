# SINH — передача работы

Версия: 0.3.0, этап 4 — зеркало и двусторонний обмен реализованы; автоматизация в работе. Исходник: локальный Git `/workspace/sinh` (main).

## Решения владельца

- Имя SINH. Windows 10/11 x64 сначала; Linux в конце отдельным портом.
- C# / .NET 10 LTS / WPF / MVVM. SDK закреплён: 10.0.404.
- Владелец уточнил «каркас Google»: **Material Design, сохраняем C# / WPF**.
- Основа UI: MaterialDesignInXamlToolkit (NuGet MaterialDesignThemes 5.4.0), реализация сообщества для WPF, не официальный WPF-фреймворк Google.
- Требования рабочего процесса и безопасности — AGENTS.md.
- Новое направление фирменного значка: голубая угловатая геометрия по присланному референсу Flutter, **два зеркальных элемента**. Ось отражения выбрана вертикальной. Последний эскиз: `design/sinh-mirror-concept.png`. Окончательное утверждение ещё не получено; три исходных значка в приложении сохранены.
- Подпись разработчика: **MSS9LN**. Каждое второе нажатие — подпрыгивание; каждое девятое — пасхалка. Счётчик общий для подписи на главной и в «О программе», живёт только в текущем процессе. При отключённых Windows-анимациях подпрыгивание/пульсация не запускаются, пасхалка открывается.
- Владелец ушёл спать: работать автономно, вопросов не задавать. В конце анимации; затем отдельные часовые проходы аудита, исправлений, оптимизации. Фиксировать реальные времена, не называть короткий тест часовым.
- В конце выгрузить исходники и артефакты в GitHub grigorywork, не менять видимость существующих репозиториев. Новый репозиторий SINH пока не найден (404); доступ gh от grigorywork доступен, токен не выводить.
- Важны длинные русские/английские пути и независимость посторонних файлов на USB. Корень диска запрещён как B: копия только в выделенной папке.
- Нужна цифровая подпись. Сертификат разработчика не предоставлен; нельзя выдавать самоподписанный сертификат за доверенную подпись Windows. Закрытый ключ не хранить в Git и не публиковать.

## Реализовано

- Отдельные проекты App, Settings, Core, Checks.
- Core: PathRules, TreeScanner, SyncPlanner, ComparisonService; хеширование SHA256, отмена, ошибки неполного чтения, защита совпадающих/вложенных корней и reparse points.
- Планы обновлений/зеркала (удаления требуют правила), Unicode/пустые папки/исключения; окно с виртуализированной таблицей операций без записи.
- Атомарная запись настроек, резервная копия конфигурации, сохранение повреждённого JSON, схема и безопасные значения неизвестных enum.
- Список пар и редактор; безопасные ручные значения по умолчанию, пауза.
- Темы/масштаб/акцент/системный шрифт, ленивые разделы настроек.
- Три PNG из закреплённого NoteLS-исходника, многомасштабные ICO, постоянный AppUserModelID.
- Черновик редактора стекла с сохранением/отменой/сбросом, лёгкая градиентная поверхность.
- DeveloperSignature: кнопка для мыши/клавиатуры с неподвижной областью нажатия и анимацией текста; EasterEggWindow с точным геометрическим отражением векторных элементов. Только UI, синхронизацию и настройки не меняет.
- StateStore / VerifiedCopy / SyncExecutor / HistoryStore: потоковое копирование, SHA256 подготовленной и целевой копии, атомарная замена, отмена, лимит истории, архив замен/удалений, восстановление с сохранением текущей версии.
- JSON-журналы применения, база только после проверки результата, уборка записанных временных файлов после незавершённого запуска. Вся пара не является одной транзакцией; завершённые файлы остаются, незавершённые требуют новой сверки.
- Подтверждение изменений B: выбор USB → компьютер или компьютер → USB, затем конкретный план.
- Двусторонний обмен по базе обеих сторон: объединение, конфликты с сохранением обеих версий, удаление против правки, файл/папка с сохранением поддерева. Длинное конфликтное имя не обрезается: отдельная подпапка с исходным именем.

- Применение: ещё 9/9 PASS, всего 22/22. Копирование/история/повтор/восстановление, устаревший план, отмена во время 8-МиБ копирования, лимит истории, удаления зеркала, case-only rename, файл→каталог, изменение источника после плана, уборка crash-журнала.

- Дополнительные проверки двусторонности/границ: 9/9 PASS, итого 31/31. Пути >500 символов, русский/английский/Unicode, история/восстановление длинного пути, посторонние файлы USB, длинное имя конфликта, вложенный регистр, удаление родителя против изменения ребёнка.

## Открытые вопросы

- Три режима реализованы в ядре. Windows-интеграция расписания/USB/трея сейчас подключается; не считать её проверенной.
- Acrylic/матовость, встроенные шрифты, English, трей, расписание, USB-агент ещё не реализованы; UI это обозначает.
- Внешний вид после перехода на Material Design требует Windows-проверки.
- Нет сертификата подписи. Целевые ОС не означают подтверждённую совместимость.
