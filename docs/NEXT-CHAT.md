# SINH — передача работы

Версия: 0.1.0, каркас этапа 1 сохранён. Исходник: локальный Git `/workspace/sinh` (main).

## Решения владельца

- Имя SINH. Windows 10/11 x64 сначала; Linux в конце отдельным портом.
- C# / .NET 10 LTS / WPF / MVVM. SDK закреплён: 10.0.404.
- Владелец уточнил «каркас Google»: **Material Design, сохраняем C# / WPF**.
- Основа UI: MaterialDesignInXamlToolkit (NuGet MaterialDesignThemes 5.4.0), реализация сообщества для WPF, не официальный WPF-фреймворк Google.
- Требования рабочего процесса и безопасности — AGENTS.md.

## Реализовано

- Отдельные проекты App, Settings, Core (пока пустой), Checks.
- Атомарная запись настроек, резервная копия конфигурации, сохранение повреждённого JSON, схема и безопасные значения неизвестных enum.
- Список пар и редактор; безопасные ручные значения по умолчанию, пауза.
- Темы/масштаб/акцент/системный шрифт, ленивые разделы настроек.
- Три PNG из закреплённого NoteLS-исходника, многомасштабные ICO, постоянный AppUserModelID.
- Черновик редактора стекла с сохранением/отменой/сбросом, лёгкая градиентная поверхность.

## Проверки

- Первая WPF cross-build на Linux прошла до подключения Material Design. Была предупреждающая диагностика switch precedence; исправлена.
- Проверки SettingsStore: 5/5 PASS, Linux x64 / .NET 10.0.404. Безопасные значения, Unicode/миграция, повреждённый конфиг, 25 конкурентных обновлений/GC/отписка, ошибка записи.
- WPF Material Design cross-build: прошла; статические ключи стилей сверены с исходником toolkit 14223ece627401f4e987fdd4ba2b1ac5674977ff. Это не runtime UI-тест.
- Windows 10/11, UI, экранный диктор, DPI, установленное приложение **не проверены**.

## Открытые вопросы

- Core ещё не реализован; кнопки сравнения и применения пока отключены.
- Acrylic/матовость, встроенные шрифты, English, трей, расписание, USB-агент ещё не реализованы; UI это обозначает.
- Внешний вид после перехода на Material Design требует Windows-проверки.
- Нет сертификата подписи. Целевые ОС не означают подтверждённую совместимость.
