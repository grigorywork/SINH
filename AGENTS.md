# SINH — отдельная Windows-программа синхронизации папок

Этот файл фиксирует инструкции владельца от 2026-11-24. Окончательное имя — **SINH**, а не FolderSync. Это самостоятельная программа, не Windows-порт NoteLS и не клиент протокола заметок NoteLS.

## Стек и работа

- Читать существующий код; продолжать выбранный стек. C#, поддерживаемый .NET LTS, WPF/MVVM; движок и настройки — отдельные библиотеки. Закреплять инструменты.
- Владелец уточнил: под «каркасом Google» имеется в виду **Material Design с сохранением C#/WPF**, не Flutter. Использовать готовые компоненты MaterialDesignInXamlToolkit.
- Windows 10/11 x64 — первые цели; подтверждать каждую проверками. Linux — отдельный порт в конце. Не объявлять Windows-приложение работающим по Linux-сборке.
- Этапы: реализация → подходящие проверки → исправления/рефакторинг → Git → короткая передача. После каждого этапа обновлять docs/NEXT-CHAT.md: версия, исходник, изменения, проверки, проблемы, следующий шаг.
- Рутинные решения принимать самостоятельно. Не покупать сервисы и не запускать платные ИИ-запросы. Тарифы, магазин, видимость репозитория — только по отдельному заданию.
- Сначала использовать временные тестовые папки. Пользовательские пути — только явно настроенные пары и выбранный режим.
- Заметки, дневник, голосовой ввод и ИИ не входят в первый выпуск. Другие функции — отдельные модули после ядра.

## UI

- Стиль NoteLS 1.10.58: ясные подписи, сетка, компактные панели, видимые состояния; главная — пары, направление, статус, последний результат, «Сравнить», «Синхронизировать», «Пауза», «Остановить».
- Небольшой выбор — плашки с выделением; длинные списки — поиск/отдельный выбор. Мышь, клавиатура, сенсор, Tab/Enter/Escape, экранный диктор; цвет дополнять подписью/значком.
- Разделы настроек раскрываемые, тяжёлое содержимое создавать лениво. Выбор обновлять сразу. Сканирование, сеть, хеширование и запись настроек — вне UI. Изменение оформления не запускает синхронизацию или сканирование дисков.
- Язык ru/en (ru); тема system/light/dark (system); стиль classic/glass (classic); масштаб .85/1/1.15 (1); акцент system/purple/blue/green/orange/pink/teal (system); шрифт system (system).
- Стекло: прозрачность 0–100 (50), матовость 0–100 (0); оттенки по теме/голубой/бирюзовый/сиреневый/розовый/янтарный/зелёный/графитовый (по теме); фон аврора/полосы/однотонный (аврора).
- Встроенные семейства: Roboto, Open Sans, Montserrat, Inter, PT Sans, Nunito, Rubik, Manrope, Playfair Display, Merriweather. Сохранять лицензии; загружать/кешировать только необходимое. Предусмотреть системные гротеск/с засечками/моно/рукописный.
- Системный DPI вместе с масштабом приложения: 100/125/150/200%, перенос между мониторами, крупный текст. Не уменьшать области нажатия вместе со значком.
- Стекло редактируется в черновике: предпросмотр, сохранить, отмена, сброс. Закрытие и отмена не пишут настройки. Размывается только фон; текст чёткий. На слабом GPU/без эффекта — лёгкая непрозрачная/градиентная поверхность. Дорогие эффекты ограничивать по частоте/применять после отпускания ползунка. Использовать Windows API для системных эффектов и акцента.
- Уточнение владельца: оставить только голубой зеркальный значок SINH. Старые розовый/матовый/лист удалить вместе с выбором. Постоянный AppUserModelID, подписанный EXE не переписывать; кеши оболочки не очищать.
- Минимум текста в приложении; убрать упоминания NoteLS из описания. Пять полезных разделов: внешний вид, пары, история и восстановление, дополнительно, о программе.
- Несколько папок можно добавлять одним выбором и отмечать галочками. Общий запуск обрабатывает только отмеченные пары по очереди. Каждая пара сохраняет независимые настройки; поддержать автоматическое направление USB → ПК.

## Настройки

- Разделы: внешний вид, пары, правила, расписание, исключения, история/восстановление, производительность, уведомления/трей, о программе.
- Глобально: автозапуск (выкл), старт свёрнутым, явно указанное закрытие; трей всегда имеет «Выход»; уведомления успех/ошибка/конфликт, лимит параллельных файлов и скорости, контрольное сканирование, срок журнала.
- На пару: постоянный ID, название, корни, режим, политика конфликтов/удалений, расписание, исключения, история, пауза, последний успех. Пара не меняет остальные.
- Единый наблюдаемый SettingsStore; корректные подписки/dispose. Проверять GC, пересоздание окон, быстрые изменения. Не подписываться при каждой перерисовке.
- %LOCALAPPDATA%/SINH, схема/валидация/миграции/атомарность. Повреждённый конфиг сохранять; неизвестные значения не должны ронять приложение. Большие журналы отдельно.
- Секреты только Windows Credential Manager/DPAPI. Экспорт без секретов; после импорта перепроверять пути/доступ. Обычные права; ошибки конкретной операции показывать явно.
- Бэкап настроек и история файлов — разные вещи. Частоты бэкапа настроек: вручную, ежедневно, 3/10 дней, месяц. Восстановление файлов — отдельная политика.

## Режимы и движок

- Безопасный исходный режим: обновления A → B, сохранять посторонние B, не переносить удаления. Новый профиль — ручной запуск, удаления выключены.
- Зеркало: точная копия по явно выбранным правилам. Первый запуск и смена корней/режима — конкретный план. Штатная настроенная автоматизация не задаёт повторных вопросов.
- Двусторонний обмен: обе стороны сравниваются с подтверждённой базой. Одновременные изменения по умолчанию сохранять обеими версиями и показывать конфликт. Изменения USB не затирать автоматическим A → B; предложить синхронизацию согласно USB и показать последствия.
- Локальные, внешние диски и доступные UNC/SMB. Прямой компьютер-компьютер протокол — будущий самостоятельный модуль.
- Разделить обнаружение/сравнение/план/применение. «Сравнить» не пишет пользовательские файлы. Новые массовые удаления/неоднозначные конфликты — отдельный план.
- Отключённый диск, недоступная сеть, ошибка доступа и неполное сканирование — не пустой каталог; удаления не планировать.
- Проверять совпадение/вложенность корней, включая junction/reparse points; ссылки по умолчанию не обходить, исключать циклы/выход за корни.
- Точные Unicode/длинные имена, case-only rename, регистрозависимые каталоги, права и блокировки. Размер/время — быстрые признаки, не единственное основание; база и хеши по необходимости.
- Потоковая копия во временный файл назначения, проверка целостности, затем замена. Не удалять оригинал до фиксации новой версии. Проверять изменение источника при копировании.
- Заменённые/удалённые версии — отдельная исключённая область восстановления; видимые лимиты/срок. Журнал операций и состояния, завершённые/незавершённые шаги. Отмена/пауза/сбой/повтор не должны портить целевой файл.
- Watcher — сигнал; debounce, overflow, контрольная сверка. Ограничить очередь/параллелизм, показывать этап/прогресс/ошибки и работающую отмену; виртуализировать файлы/журнал.

## Этапы и проверки

1. Каркас/SettingsStore/темы/плашки/масштаб/стекло/список/значки.
2. Сравнение и план без записи.
3. Копирование обновлений/отмена/история/восстановление.
4. Зеркало/двусторонность/конфликты/удаления.
5. Наблюдение/расписание/трей/уведомления.
6. Производительность/сбои/упаковка/инструкция.

- Проверять конфликты, повторы, место, блокировки, изменение файла, отключение USB/SMB, overflow, длинные имена, case-only rename, вложенные корни, восстановление сбоя.
- Воспроизводимый набор мелких и крупных файлов: размер, время, память.
- Windows UI — на Windows; фиксировать реально запущенные ОС/архитектуры. Сборка, ядро, UI и установленное приложение — отдельные результаты.
- Выпуск: версия/исходник/проверки/SHA256/portable или установочный артефакт. Без сертификата — неподписанная сборка; Android-ключ неприменим. Identity постоянная, секреты в Git не экспортировать.
- Источник настроек — код NoteLS 1.10.58 (SettingsRepository.kt, GlassAppearance.kt, GlassSettingsDialog.kt, LauncherIcons.kt), не личные настройки телефона. Android API/Room/ключи/протокол заметок не переносить в Windows-движок.

## Уточнение публикации от владельца

SINH должен быть **в открытом доступе**: публичный GitHub-репозиторий и публичные portable/source-артефакты Releases. Это явное разрешение владельца на публичную публикацию данного проекта. Закрытый ключ подписи остаётся вне Git и Releases.
