# SINH — текущий этап 0.5.0-preview.1

Исходник: текущая ветка main, следующий commit содержит этот этап. Последний опубликованный EXE пока 0.4.0-preview.3 (ссылка ниже); новая версия ещё не выпущена.

## Реализовано

- Только голубой зеркальный значок: старые PNG/ICO и настройка выбора удалены. Старое поле Icon в JSON безопасно игнорируется.
- Пять ленивых разделов настроек, реальные действия с парами и историей, краткое «О программе» без NoteLS.
- Множественный OpenFolderDialog, галочки выбранных исходников, отдельные копии внутри общего назначения. Точные имена не обрезаются; одинаковые назначения отклоняются.
- Галочки главного списка сохраняют включение/паузу пары. Общий запуск последовательно обрабатывает отмеченные пары; отмена/отказ/ошибка останавливает очередь. Автоматический scheduler не вклинивается в ручной пакет.
- USB → ПК: отдельное направление у каждой пары, исходный том привязан по GUID; диалог выбора направления учитывает сторону USB.
- Рефакторинг: единый FolderPairEditor для главной/настроек, независимый FolderSelection для проверки и отображения выбранных корней; настройки пар вынесены в отдельный partial.

## Проверки этапа

Linux cross-build: 0 warnings/errors; ядро и настройки: 60/60 PASS (включая множественный выбор, Unicode, коллизии, старые значки и независимость USB-направления).
Windows WPF/ядро: требуется новый GitHub Actions run после push. Добавлены проверки последовательности, галочек, остановки/отказа, перепривязки исходного USB и недоступного тома. Сборка на Linux не является запуском Windows UI.
Открыто: Windows 10/11 client, реальные USB/SMB, DPI, стандартный пользователь. Не объявлять выполненными по Server CI.
Следующий шаг: Windows CI → исправления → подписанный portable/EXE → packaged smoke → публичный GitHub Release с SHA256.

Несовместимый Merriweather заменён на оригинальные static2.002 upstream Google Fonts b848f42f... с OFL; остальные9 семейств не изменены. Бинарникpreview2 с дефектом только дополнительного шрифта был выдан отдельно, актуаленpreview3.

## Публикация

Cloud CLI upload-host возвращал401, поэтому подписанные архивы переданы через временную release-assets ветку, а поддерживаемый GitHub Actions workflow проверил хеши/источник/первый запуск и опубликовал EXE/ZIP/source/bundle/сертификат/JSON/SHA. Старый пустой draft1 удалён; временная ветка удалена после успешной публикации. Main содержит исходник, без больших бинарников. Локальные пакеты в artifacts/release; пользовательские прежние download-файлы не удалены.
