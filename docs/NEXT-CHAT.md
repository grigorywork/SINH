# Текущий этап — диагностика ошибки корня 0.5.1-preview.1

Пользователь удалил один файл; SINH сообщает «Папка недоступна» для F:\изображения\Wallpapers, хотя папка открывается в Проводнике. Скриншот: двусторонняя пара F:\изображения\Wallpapers ↔ F:\Обои; обе стороны одного диска. Причина реального сбоя пока НЕ воспроизведена и не считается исправленной.

Изменения: RootAccessException различает missing/access denied/not directory/I/O с нативным кодом и inner exception; File.GetAttributes вместо подавляющего ошибки Directory.Exists в Root. Никаких автосозданий недоступного корня или пустых снимков. SyncFailureReport сохраняет локальный JSON в %LOCALAPPDATA%/SINH/errors (не больше100, срок LogDays), без содержимого файлов и автоматической отправки. Кнопка «Копировать ошибку» видна только при ошибке. Стек, настроенные/разрешённые пути и повторная проверка атрибутов помогают поймать transient/mount/access причины.

Проверки: Linux — 62/62, в том числе удаление последнего файла в обе стороны с разрешёнными/запрещёнными удалениями, stable GUID paths на Windows при дальнейшем CI; корни сохраняются, повтор идемпотентен. Missing/file-as-root различаются и не дают план. Windows проверки и новый пакет ещё ожидаются. Нельзя объявлять пользовательский сбой исправленным без повторной проверки на его машине/диагностики.

Следующий шаг: Windows CI, диагностический подписанный preview, Windows packaged smoke, публичный Release; при повторе пользователь нажимает «Копировать ошибку». Предыдущая опубликованная версия ниже.

## Изменения

- Выбор нескольких исходных папок через Windows OpenFolderDialog (Ctrl/Shift), затем галочки. Несколько источников получают отдельные копии внутри назначения с точными именами. Коллизии имён отклоняются.
- Галочки главного списка сохраняют включение/паузу каждой пары. Общий запуск обрабатывает отмеченные пары по очереди. Отмена, отказ от плана или ошибка останавливает очередь; фоновая автоматика не вклинивается. Снятая галочка отключает и автоматический запуск.
- Направления ПК → USB / USB → ПК, постоянный ID исходного и целевого томов. При подключении исходной флешки профиль может автоматически обновлять папку ПК после первого успешного ручного запуска. Расписание, исключения, история и удаления независимы у каждой пары.
- Только голубой зеркальный значок; старые PNG/ICO и выбор удалены. Старое поле Icon безопасно игнорируется при загрузке.
- Пять полезных ленивых разделов: внешний вид, пары, история и восстановление, дополнительно, о программе. Информационные заглушки и описание NoteLS из интерфейса удалены.
- Рефакторинг: FolderSelection сопоставляет выбранные корни; неизменяемый FolderPairDraft проверяет их вне UI; FolderPairEditor — единый сценарий редактирования/сохранения для главной и настроек. Пересечения проверяются до создания каталогов. Ожидание завершения при закрытии защищено от повторного входа.
- Непарные файлы флешки не включаются в синхронизацию. История/защитные версии и проверки длинных русских/английских/Unicode имён сохранены.

## Открыто и следующий шаг

Реальные клиентские Windows10/11, USB/SMB, стандартный пользователь, DPI100/125/150/200/несколько мониторов, сенсор/Narrator остаются непроверенными. Windows Server CI их не заменяет. Linux GUI — после Windows. Использовать docs/WINDOWS-VALIDATION.md; новые файловые проверки только на временных папках.
Не запускать новые часовые стресс-прогоны для одних косметических изменений без причины. Предыдущие часовые отчёты относятся к своим SHA, не автоматически к новому EXE. Автозапуск по умолчанию выключен, первая синхронизация ручная с планом, штатная настроенная автоматика без повторных вопросов. MSS9LN: прыжок каждое второе нажатие, пасхалка девятое; reduced-motion сохраняется.

Проблема со скачиванием локальной /workspace-ссылки решена публичным GitHub URL. Пользователю выдавать прямую публичную EXE-ссылку; отличать скачивание от ошибки запуска.
