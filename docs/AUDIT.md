## Находки

### A-001 — двусторонний конфликт файл/каталог после подтверждённой базы

Случайный seed 1000045 и 1000077 выявил потерю версии каталога из видимых деревьев (версия оставалась в истории): если на B прежний каталог заменили файлом, а A-каталог не менялся, правило переноса удалений удаляло его детей. При конфликте типов выбранный каталог должен сохраняться целиком независимо от удаления детей на стороне файла.

Детерминированная регрессия воспроизвела ошибку: 31/32 теста до исправления. Добавлено сохранение всего выбранного поддерева A; после исправления 32/32 PASS. Исходный часовой прогон продолжает тестировать прежнюю сборку для полноценного отчёта, поэтому обнаружения A-001 в нём ожидаемы. Исправленную сборку проверит отдельный проход.

## Продолжение находок

### A-002 — оформление новых окон

Оформление применялось к открытым окнам при активации приложения. Новое окно в уже активном приложении могло получить стандартный шрифт/масштаб/значок. Исправлено: общие DynamicResource для шрифта, размера и значка; статический Loaded-handler с WeakReference для нативного фона, без удержания закрытых окон. Добавлены Windows runtime-проверки.

### A-003 — альтернативные пути Windows

Лексическая проверка не распознавала `C:\folder` и `\\?\C:\folder` как физические алиасы. Добавлено сравнение окончательного пути через handle/ID, проверка предков, отдельная Windows-регрессия. Linux cross-build проходит; runtime-проверка Windows ожидается.

### A-004 — подтверждение направления и штатная двусторонность

Политика подтверждения вынесена из UI-координатора в PlanReviewPolicy. Обратное USB → PC направление сравнивается со своим fingerprint и получает конкретный план. Односторонние изменения B в двустороннем режиме не требуют повторного вопроса, пока нет конфликтов или массовых удалений.

### A-005 — источник операции

Дополнительно ограничен источник каждого payload: он должен принадлежать одному из двух подтверждённых снимков и совпадать с Entry по содержимому. Внешний сконструированный план больше не может копировать данные из произвольного третьего каталога.

### Предстоящие проверки исправлений

- Пропуск вложенных ссылок/исключённых поддеревьев с защитой от удалений.
- Восстановление после сбоя при сменившейся букве/идентичности носителя.
- Ограничения FAT32, повреждённая история, реальные Windows-блокировки.
- Планировщик и настройки: закрытие/GC, ограничение очередей, корректное освобождение ресурсов.

## Границы подтверждения

Файловые runtime-проверки выполняются на Debian Linux x64 / .NET 10; они не подтверждают Windows GUI, драйверы USB, Windows-блокировки, NTFS/FAT/exFAT/SMB, DPI и Narrator. WPF cross-build учитывается отдельно.
