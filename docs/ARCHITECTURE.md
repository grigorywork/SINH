# SINH

```
src/
  Sinh.App/
    App.xaml(.cs)          Запуск и время жизни процесса
    Controls/              Подпись MSS9LN
    Infrastructure/        Observable и команды
    ViewModels/            Состояние главного окна и пар
    Views/                 Main, Pairs, Plans, History, Settings, About
    Services/              Координатор, оформление, фоновые расписания
    Platform/Windows/      ID носителей, автозапуск, один процесс, трей
    Assets/                PNG и ICO
  Sinh.Core/
    Models/                Снимки, запросы, операции, планы, конфликты
    Discovery/             Границы корней и полное сканирование
    Planning/              Сравнение и построение плана
    Execution/             Проверенное копирование и журнал применения
    Persistence/           База сравнения и история версий
  Sinh.Settings/           Схема, валидация и наблюдаемый SettingsStore
tests/Sinh.Checks/          Проверки на временных данных
```

UI не выполняет файловые операции напрямую. Координатор запускает их на worker-потоке; SettingsStore сам переносит запись в пул потоков. Одновременно применяется одна пара; файловые события объединяются и означают необходимость полной сверки.

«Сравнить» строит план без записи пользовательских данных. План привязан к настройкам и снимкам; применение перепроверяет обе стороны, подготавливает данные, проверяет временный файл назначения и затем заменяет конечный файл. База сравнения обновляется только после успешной проверки результата. Весь набор файлов не является одной транзакцией.

Файлы за пределами настроенных корней не участвуют в синхронизации. B не может быть корнем диска. Windows-помощник узнаёт USB по ID тома и проверяет этот ID перед заменой/удалением; файлы на соседних участках флешки на это не влияют.

Настройки, база, журналы и история лежат в `%LOCALAPPDATA%/SINH`. Эти каталоги не должны входить в синхронизируемые корни. Пароли не запрашиваются и не хранятся; UNC использует текущую доступную сессию Windows.
