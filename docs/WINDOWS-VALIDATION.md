# Проверка Windows — ещё не выполнена

Цели: Windows 10 22H2 x64 и Windows 11 x64. Фактически ядро запускалось на Debian 13 x64. Кросс-сборка WPF, тесты ядра, WPF runtime и запуск portable-пакета — разные результаты. GitHub Windows CI пока не запущен из-за запрета создания репозитория подключённой интеграцией. Даже успешный Windows Server runner не подтверждает Windows 10/11 клиента.

## Автоматически на Windows

Запустить PowerShell из исходника: `scripts/Check-Windows.ps1`. Используется закреплённый SDK; нужны Windows Desktop runtime-компоненты SDK. Скрипт сохраняет сведения об ОС, вывод проверок и снимки WPF-окон в `artifacts/windows-validation` и `artifacts/windows-ui`.

Ядро дополнительно проверяет Windows FileShare.None и настоящие GUID-пути томов. WPF проверяет загрузку ресурсов Material Design, иконок, десяти шрифтов, lazy settings, обновления после GC, масштабы .85/1/1.15, RU→EN, закрытие черновика стекла, счётчик/подпрыгивание/девятое нажатие MSS9LN и Escape.

## На каждой клиентской ОС

- Распакованный portable без установленного .NET: запуск, подпись файла, обычные права, выход. Свежий профиль и повторный запуск.
- DPI 100/125/150/200%, размер текста Windows, масштаб приложения .85/1/1.15, перенос между мониторами. Проверить нижние кнопки/прокрутку, длинные пути, горячие области. Снимки фиксировать с указанием DPI/разрешения.
- Tab/Shift+Tab/Enter/Escape, Narrator, мышь, сенсор. Состояния доступны подписью, а не только цветом.
- Светлая/тёмная/системная тема, системный акцент; смена оформления не должна запускать сравнение. Mica на Win11 при доступности, fallback на Win10/слабом GPU/High Contrast.
- Временные пары: updates/mirror/two-way, массовые удаления, конфликты, повтор, восстановление и лимит истории, пустые каталоги, скрытые файлы, русские/английские/Unicode/длинные пути, case-only rename.
- NTFS/exFAT/FAT32 USB: физическое отключение во время записи, смена буквы, другой носитель на прежней букве, замена файла на папку, восстановление после аварийного завершения. Посторонние файлы вне B должны остаться неизменными.
- FAT32 >4 ГиБ, реальная нехватка места, ACL/access denied, read-only файл/носитель, заблокированный файл, изменение источника во время чтения. Исходная версия назначения должна остаться целой при неудачной замене.
- UNC/SMB: отключение сети/переподключение/запрет доступа, длинные имена; ошибка чтения не даёт план удаления.
- Наблюдение: серия событий, переполнение, пропущенные события при занятой программе, контрольное сканирование. Ограниченная очередь и работающие отмена/пауза.
- Помощник: HKCU Run из portable, переход на локальный EXE, безопасное извлечение флешки, вход Windows, режим трея и явный «Выход». Секреты не экспортируются.

Сохранить версию ОС/сборку/архитектуру, SHA256 EXE, исходный commit, результат каждого пункта и обнаруженные проблемы. Не отмечать пункт выполненным по наличию его в тестовом коде.
